# Code

This is the source-code root for the Savoury project.

To avoid breaking the existing build, deploy, and import
paths, the three application components live in their own
top-level folders at the repository root rather than being
physically moved under `code/`:

| Component | Location | Stack |
|-----------|----------|-------|
| Backend API | [`../backend-api`](../backend-api) | Express + TypeScript + Prisma (PostgreSQL) |
| Web console | [`../web`](../web) | Vite + React (admin / warden / staff) |
| Mobile app  | [`../mobile`](../mobile) | Expo / React Native (students) |

The Expo scaffold at the repository root (`../app`,
`../components`, `../hooks`, `../constants`, `../assets`)
is the template generated by `create-expo-app`; the real
student client is in [`../mobile`](../mobile).

## Build / run

See the top-level [`README.md`](../README.md) and the
